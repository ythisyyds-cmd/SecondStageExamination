# 目标检测与图像分割任务报告

这一项任务我选择YOLOv8来做并不是因为比较之后觉得它有什么特别明显的优势，而是前一段时间加入的一个SRTP项目要用YOLOv8，所以当时下载了模型。这段时间项目没继续推进，我也没使用过它，这次正好借考核来简单练习一下。

项目中使用yolov8n.pt完成目标检测，使用yolov8n-seg.pt完成实例分割，两个模型使用的是已经训练好的参数，没有重新训练。目标检测会用检测框标出物体的位置，同时给出类别和置信度。实例分割除了这些结果，还会用遮罩标出物体更具体的轮廓。程序在显示处理后的图片的同时会把结果保存到outputs文件夹中。

我之前搭建和训练简单的网络时，面对的是MNIST和CIFAR-10这种整理好的数据集，最后得到的是测试集准确率或者预测类别。这次运行第一段YOLOv8代码时，比较直观的感受首先是模型调用很方便。我只写了一段比较简单的代码，就能让它处理我网上找的图片和自己拍摄的照片，得到检测框和分割遮罩。每次改变输入的图片都可以看到丰富的结果，这让我第一次明显地感觉到自己有用模型处理实际问题的可能性。

最开始使用的样例是第一阶段测试ResNet18时用过的马的照片。因为图片中只有一匹明显的马，所以检测框和类别判断都很准确，分割遮罩也基本覆盖了马的身体，只在部分边缘和马尾的位置有一点点偏差。这个结果证明了程序能够正常运行。

之后我又拍了自己窗外的停车场。模型识别出了不少汽车，但是有些车彼此距离比较近，有的被树遮住了一部分，因此出现了漏检，图片上的标签也有一些重叠。我感觉模型能够根据图片中的特征找到物体，但并不理解它们在空间中的位置关系。物体变小、被遮挡或者集中在一起以后，处理效果就会明显下降。

书桌照片同时表现出了模型的灵活性和局限性。YOLOv8不是刚发布的新模型，我的电脑却是去年买的，它仍然能够很好地识别出笔记本电脑，并且分割遮罩接近完整地覆盖了轮廓。鼠标也被正确识别，模型还认出了桌面上的本子，只是对本子的置信度比较低。它把耳机的一个耳罩误判为了鼠标，而真正的鼠标则在耳机旁边，一张书桌上同时放两个鼠标的情况并不常见，这让我感觉模型只是在根据局部外观判断物体，而不具备现实生活中的经验。

我之后把置信度阈值调整到了0.5。调整后，对耳机的误判消失了，但原来正确识别却置信度不高的本子也一起消失了。这说明提高阈值能过滤掉一部分不可靠的结果，却也可能让模型不再输出原本判断正确的物体。阈值并不是越高越好，具体设置多少还是要看实际任务更在意误判还是漏检。现在选择0.5主要是为了让最终显示的结果更稳定。

和第一阶段手动搭建BP网络和ResNet18相比，这次的工作量下降了很多，阅读和调用接口也比自己处理网络结构、训练过程和张量形状轻松。用简明的代码就能完成比较复杂的功能，这个过程很方便，也很奇妙。不过现成模型能够理解的类别和场景实在是有限，如果以后需要识别新的物体，或者改善远距离、遮挡和误判问题，还需要准备数据进一步训练。第一阶段手动搭模型的经验虽然没有直接对写这次的代码产生影响，但我觉得以后进一步训练和调整模型时会有帮助。
