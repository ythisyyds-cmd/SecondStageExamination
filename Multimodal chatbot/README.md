# MiMo多模态聊天机器人

调用mimo-v2.5模型来实现可以接收文字和图片的多模态聊天机器人，没有使用现有的大模型应用框架。

目前已经完成文字交流、上下文记忆、聊天记录清空以及图片问答功能。支持传入JPG、JPEG和PNG格式的图片，文字和图片消息可以在对话中交替输入。

程序使用链式思考（CoT）提示先分析用户请求，再使用链式提示（Prompt Chaining）把分析结果交给第二次模型调用并生成最终回答。

在项目根目录的.env文件中配置MIMO_API_KEY，然后在VS Code中直接运行chatbot.py即可。输入文字可以进行对话，输入“图片”然后提供图片路径就可以针对图片提问，输入“清空”清除聊天记录，输入“退出”结束程序。
